### About

**ImprintJS** is a browser fingerprinting and device intelligence platform. 
It gives developers the tools to read browser and device signals from the
client side, helping applications recognize returning visitors and identify
suspicious or automated activity.

### Development & Community

ImprintJS is in early, active development, built with an open-source first approach, 
focused on transparency, developer experience, extensibility, and practical browser intelligence.
